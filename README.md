# 野水 · LURE — Windows 单机开发版

## 开始游戏
双击 PlayGame.cmd，或打开 Release/Encounter-20260914/Windows/LureGame.exe。首次启动会进入中文菜单，点击“开始钓鱼”。
开发者也可双击 PlayPrototype.cmd，从本机 UE 环境运行相同玩法。

## 玩法
- WASD 移动，鼠标直接控制视角，不需要按住鼠标拖动。
- 按住左键蓄力，松开抛投；按住右键收线；空格抽饵或在咬口时刺鱼。
- 收线和停顿交替、适时轻抽可以让跟随的鱼发起攻击。咬口计时进入亮区时按空格，挂钩更稳。
- 搏鱼时鱼会左右冲刺、下潜、甩头和洗鳃。鱼发力时松开右键，按提示压竿，回气时争取收线距离。
- 鼠标或 A/D 左右压竿，W/S 抬高或压低竿尖，滚轮调整泄力。按键控竿优先于鼠标偏转。
- 鱼到岸边后，在 4 秒窗口内按空格完成抄鱼；错过后鱼会再次挣开一段。
- Tab 在抛投前切换拟饵；V 水下观察/上鱼近景；R 收竿或放流。
- Esc 打开菜单，可查看鱼获、切换天气/时段/标点、调整画质与音量。

## 内容
一张湖湾，沉木湾、芦苇浅滩和岩石岬角三个岸钓位置。
四种鱼：大口黑鲈、河鲈、白斑狗鱼、虹鳟。
五种拟饵：悬浮米诺、软虫、旋转亮片、水面波爬、铅头钩。
晴朗、阴天、薄雾、小雨；清晨、午后、黄昏、夜晚。
鱼会巡游、追饵、攻击和逃开。停顿、水层、鱼种、天气和时段影响鱼口。

## 存档
上鱼与修改设置时自动保存。菜单“保存并退出”正常退出。
保存鱼获鱼种、重量、长度、拟饵、时间、评分、刺鱼质量与搏鱼时长，最近 100 条；手册显示最近 8 条。
每尾鱼按操作质量获得评分和经验，首次鱼种与刷新该鱼种重量纪录有额外奖励。
存档由 UE 的本地 SaveGame 机制保存，文件名 WildwaterV1.sav。
自动测试使用独立测试存档，不覆盖玩家存档。

## 性能
面向 Windows 键鼠单机，建议接电源运行，先使用“均衡”画质。
本项目结合项目制作的网格、经许可的人体/动画来源和 CC0 扫描资产；具体来源见 Docs/Credits.md。当前仍需打磨动作、场景和持续游玩体验。
没有联网、手机陀螺仪、船钓和装备商店。
