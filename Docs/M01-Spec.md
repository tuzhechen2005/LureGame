# M01 玩法原型验收与实现边界

目的：验证从岸边抛投到上鱼的可重复交互，不代表最终画质。

状态：Ready → Charging → Flying → Retrieving → Bite → Fighting → Landed。
异常：抛到岸上返回 Ready；漏刺返回 Retrieving；鱼线过载返回 Ready；R 主动重置。

单位：UE 厘米，HUD 米；弹道重力 980 cm/s²；蓄力 1.5 秒；刺鱼窗口 1.3 秒。
输入：鼠标左键抛投，右键持续回收，空格抽饵/刺鱼，滚轮泄力，Tab 切饵。

自动运行检查：使用 UnrealEditor-Cmd.exe 加项目路径和 -game -nullrhi -nosound -unattended -LureSmokeTest。
通过条件：退出码 0，日志 LURE_TEST COMPLETE failures=0。
覆盖：初始状态、蓄力、起抛、入水、出现鱼口、漏刺恢复、刺鱼、成功上鱼、重置换饵、过载断线。
此检查直接推进游戏状态，不替代键鼠交互试玩，也不验证 GPU 性能。

下一轮人工验收：
- WASD 四方向和同时反向按键是否正常；鼠标转向是否舒适。
- 轻抛/满蓄力距离是否有清晰差异；画面上鱼线是否清楚。
- 两种拟饵的停顿和下沉是否可感知。
- 降泄力/停止收线能否形成有意义的操作选择。
- 记录连续 15 分钟试玩的问题，之后再调整参数。

已知简化：岸边位置矩形约束、无角色碰撞行走；临时基础几何；确定性鱼口；无实体鱼；无声效；无存档；未制作发行包。
正式版本必须补充：独立数据资产、模块化物理、实体鱼行为、水下可见反馈、竿弯曲与鱼线模拟、手臂动画和声音。
