# Windows 单机 V1 交付范围

目标：可以独立启动、完成教学、重复岸钓并保存鱼获的完整小型单机游戏。
一张湖湾，三个可切换岸钓位置；第一人称键鼠操作；五种拟饵；四种形态不同的淡水鱼；四种天气和四个时段。

必须完成：
- 移动与鼠标转向可同时使用；鼠标捕获、暂停和返回可靠。
- 会变化的湖面波纹、入水扩散波、林岸与标点；第一人称双手、竿弯曲、摇柄动画。
- 实体鱼巡游、追饵、攻击、逃开、搏鱼和上鱼近景；鱼种和天气影响鱼口。
- 中文开始/暂停/设置/鱼获界面；鼠标灵敏度、音量和画质可调；简明操作教学。
- 本地保存鱼获、个人纪录和设置，正常退出不丢失。
- 环境声、抛投/入水/咬口/收线反馈。
- Windows 独立打包，在本机验证菜单、玩法、存档、声音和渲染。

不纳入 V1：联网、手机体感、商店/付费经济、大世界、多湖区、职业剧情。
美术采用项目原创 Blender 资产与程序材质；属于独立游戏体量，不以大型商业模拟器的资产量作为交付承诺。
